# Diabetes Prediction Using Machine Learning

A machine learning project that predicts whether a person is diabetic or non-diabetic based on medical data.

## Features

- Data preprocessing using Pandas and NumPy
- Train-test data splitting
- Support Vector Machine (SVM) model
- Diabetes prediction for custom input values
- Model evaluation with accuracy score

## Dataset

The project uses the PIMA Indians Diabetes Dataset.

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## Project Structure

```
Diabetes-Prediction/

├── diabetes.csv

```

## Model Accuracy

Training Accuracy: ~78%

Testing Accuracy: ~77%

## How to Run

1. Clone the repository

```bash
git clone https://github.com/ashrutprakash72/Diabetes-Prediction.git
```

2. Install dependencies

```bash
pip install numpy pandas scikit-learn
```

3. Open Jupyter Notebook

```bash
jupyter notebook
```

4. Run `DP_code.ipynb`
